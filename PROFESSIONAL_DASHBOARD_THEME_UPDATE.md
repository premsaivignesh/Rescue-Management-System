# Professional Dashboard Theme Update

The department/professional dashboard now shares the citizen interface's dark charcoal, black-green, and olive palette. The update styles the department sidebar, status statistic cards, recent incident cards, incident queue cards, detail panels, notifications, profile page, and refresh controls with consistent typography, spacing, rounded corners, and olive borders.

No incident logic or trained model files were intentionally changed as part of this visual update. The existing pytest suite passes and the GUI modules compile successfully. Please launch the app on Windows to confirm the final visual fit on your screen size.
